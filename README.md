# 三款小游戏

三个纯前端、单文件、零依赖的浏览器小游戏。每个游戏均为一个独立的 `.html` 文件，内联了全部样式与脚本，**无需构建、无需联网、无外部依赖**，双击即可在浏览器中运行。

## 游戏列表

| 文件名 | 名称 | 类型 | 玩法一句话 |
| --- | --- | --- | --- |
| `铁砧要塞.html` | 铁砧要塞：蓝图纪元 V3 | 双摇杆装甲作战 | 操控装甲单位迎击多波敌军，整备底盘、主炮与战术模块 |
| `夜篱苗圃.html` | 夜篱苗圃：雾灯夜守望 | 塔防策略 | 在十二线苗圃布设雾灯塔，抵御夜潮守住核心 |
| `行囊决斗场.html` | 行囊决斗场：投币赛季 | 背包整理对战 | 在有限行囊格内编排装备，与对手轮番决斗争夺十胜 |

## 运行方式

- **本地直接打开**：双击任意 `.html` 文件，或打开 `index.html` 导航页后点击进入。
- **部署到 GitHub Pages**：将本仓库推送至 GitHub，在仓库「Settings → Pages」选择 `main` 分支的根目录即可；`index.html` 会作为站点首页自动生效。
- **任意静态服务器**：`python -m http.server` 后访问 `index.html` 亦可。

## 技术说明

- 每个游戏是单一 HTML 文件，所有 CSS 与 JavaScript 均内联，不引用任何外部脚本、样式表、字体或图片。
- 进度数据保存在浏览器 `localStorage`，不会上传到任何服务器。
- 支持桌面键鼠与移动端触控；移动端已做视口适配与触控热区优化。
